**Histopathologic Cancer Detection Using DNN**

Members: Brett Phillips, Irie Slabach, Jonah Whites

**Summary:**
This repo will contain all of the associated documents with our DNN project. DNN_midterm.py contains all of the related code, for both linear and CNN models.

**Dataset:**
The dataset we are using can be found at this link: https://www.kaggle.com/competitions/histopathologic-cancer-detection/data. Due to its size, it is not included in the github.
